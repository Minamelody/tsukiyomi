# Threads投稿カード（1080×1350）

`gen_cards.py` で生成。AI生成画像は使わず全要素コード描画（`gen_brand.py` のブランド要素を再利用）。
AI表記なし。本文にURLを貼らない運用のため、屋号とURLはカード足元に控えめに焼き込んである。

| ファイル | 対応テンプレ | 投稿枠 | 使い所 |
|---|---|---|---|
| card-t1-koyomi-1080x1350.png | T1 暦×時間窓 | 8:00 | 選日＋有効時間を主役に。日付・選日・時間・絵文字を差し替えて日替わりで使う |
| card-t2-pain-1080x1350.png | T2 痛み名指し | 13:00 | 具体的な悩みを名指し。テーマ替えで量産可 |
| card-t3-night-1080x1350.png | T3 独白 | 21:00 | 左揃えの独白トーン。夜の時間帯に読む人へ |

`_cards-contact-sheet.png` は3枚の一覧確認用（納品対象外）。

## ジェネレータからの呼び出し（v2向け）

投稿1本ごとに1枚出す想定。JSONを渡すだけで完結する。

T1の `senjitsu` / `window` / `window_name` は**必ず senjitsu モジュールの計算結果を渡す**。
参考投稿の時間を流用しない（暦の裏付けが無い数字はこのカードの土台を崩す）。

```python
import datetime, senjitsu, rarity
from gen_cards import render

d = datetime.date.today()
plan = rarity.plan(d)
if plan["use_T1"]:                       # tier2以上の年79日だけT1に回す
    w = senjitsu.peak_window(d)          # その日の十二支＝時辰
    wd = "月火水木金土日"[d.weekday()]
    render({"template": "t1",
            "senjitsu": " × ".join(plan["labels"]),
            "date_label": f"{d.year}年{d.month}月{d.day}日（{wd}）",
            "window": w["label"],        # 例 "13:00〜14:59"
            "window_name": w["name"],    # 例 "未の刻"
            "emoji": "🌊"}, out_path)
else:
    ...                                  # T2 / T3 に回す
```

```bash
# CLIから（値は上と同じくsenjitsu由来のものを入れる）
python3 gen_cards.py -o out/2026-09-06-am.png --spec '{
  "template": "t1",
  "senjitsu": "一粒万倍日 × 母倉日 × 天恩日",
  "date_label": "2026年9月6日（日）",
  "window": "13:00〜14:59",
  "window_name": "未の刻",
  "emoji": "🌊"}'

# T2（昼・痛み名指し）
python3 gen_cards.py -o out/2026-09-10-pm.png --spec '{
  "template": "t2",
  "pain": ["眠りが浅く", "朝がつらいあなたへ。"],
  "body": ["体ではなく", "巡りの時期の問題です。"],
  "emoji": "🌙"}'

# T3（夜・独白）
python3 gen_cards.py -o out/2026-09-10-night.png --spec '{
  "template": "t3",
  "hook": ["この時間に", "これを読んでいる人へ。"],
  "body": ["眠れないのではなく", "まだ終われないだけ。"],
  "emoji": "💫"}'
```

- `--spec-file <path>` / `--spec-file -`（標準入力）も可。
- Pythonから直接: `from gen_cards import render; render(spec_dict, out_path)`
- `--samples` で上表の3枚とコンタクトシートを再生成。

## 環境チェック

`requirements.txt`（Pillow）では**フォントは担保できない**。ランナー環境の初回セットアップ時に:

```bash
python3 gen_cards.py --check-env    # 不足があれば終了コード1
```

必要なのは Noto CJK の4本（`fonts-noto-cjk`）。無いと**代替なしで停止**する。
絵文字フォント（`fonts-noto-color-emoji`）は無くても絵文字を省いて描画を続行する。

## 文字数の上限（超えると例外で停止する）

自動生成で崩れた画像が投稿されるのを防ぐため、長すぎる文面は描画せず `ValueError` で落とす。
呼び出し側で捕まえて、その枠をスキップするか文面を作り直すこと。

| テンプレ | 制約 |
|---|---|
| T1 | 選日 合計34字以内／1つの日名11字以内、date_label 20字以内、window 16字以内、window_name 8字以内 |
| T2 | pain 2行以内・1行22字以内、body 3行以内・1行22字以内 |
| T3 | hook 2行以内・1行18字以内、body 3行以内・1行20字以内 |

## 運用の約束（コードでは縛れない部分）

- **選日は実在するものだけ。** 暦の事実であることがこの訴求の土台なので、ここを作ると全部崩れる。
- **時間窓も実在の根拠から出す。** `peak_window()`（その日の十二支と同じ時辰）を使う。
  参考投稿の「5:00〜8:59」は卯の日の窓で、他の日に流用すると裏付けが無くなる。
- **T1は `rarity.plan().use_T1` が真の日だけ。** 天恩日単独（年59日）まで選日を主題にすると、
  年5日しかない3種重なりと同じ熱量になり特別さが消える。空いた日はT2/T3で回す。
- **実績数値（「◯◯名を鑑定」）は入れない。** 新規アカウントのため事実にならない。
- **投稿本文とカードで同じ文を繰り返さない。** 本文＝呼びかけ＋絵文字CTA、カード＝事実と情景。
- 日付・時刻を焼いたカードは**当日限りで破棄**。失敗枠の翌日流用はしない。
- 絵文字は投稿ごとに変える（返信の集計対象を分けられる）。

## 技術メモ

- 絵文字は NotoColorEmoji が 109px 固定サイズしか受け付けないため、109pxで描画→クロップ→
  LANCZOS縮小して合成している（`emoji_img`）。日本語フォントだけでは豆腐になる。
  絵文字フォントが見つからない環境では絵文字を省いて描画を続行する（停止はしない）。
- `gen_brand.py` は複数の候補パスから探索する。リポジトリ側で配置が変わっても動くが、
  見つからない場合は探索したパスを表示して停止する。
- T1の選日は「×」区切りで行に詰め、日名の途中で改行しない。長い場合はフォントを1段落とす。
- 足元（屋号＋URL）は金枠の内枠（H-45）に触れないよう `fy = H - 196` に固定。
  ここを下げるとURLの下端が枠線と重なる。変更する場合は必ず3テンプレとも下部を目視確認する。
- T3は左揃えの独白トーンなので、中央寄せの足元ラベルは置かない（`footer(d, None)`）。
  左揃えの本文と中央寄せの小文字が同じ高さに並ぶと不揃いに見えるため。
