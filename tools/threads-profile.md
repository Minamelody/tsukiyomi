# Threads プロフィール（bio）と検索対策

## 前提: アカウント作成日（2025年10月）は不利になりません

Threads の表示順は「アカウントの古さ」ではなく投稿単位の反応で決まります。
Google の検索順位のような累積ドメイン評価が効く仕組みではないので、
2025年10月作成でハンデはありません。むしろ**古いアカウントの方が不利になる要素**が1つあります
（下の「作成日より効く問題」）。

## bio 案（150字以内）

```
姓名判断・星座・タロット・四柱推命・西洋占星術
5種類の占いを毎日ひとつずつ。

生年月日を入れるだけの無料鑑定 ↓
```

リンクは bio のリンク欄に入れます（**投稿本文にURLを貼らない** — リーチ抑制の報告があります）。

## 表示名（検索で効くのはここ）

Threads のキーワード検索は表示名とユーザーネームを強く見ます。屋号だけだと
「占い」で検索した人に当たりません。

- 変更前: `ツキヨミ`
- 変更後: **`ツキヨミ｜無料占い・姓名判断`** ← 屋号＋検索語を同居させる
  （AI表記なしで確定。サイト・鑑定書・ココナラ出品文と揃えています）

「占い」「無料占い」「姓名判断」「タロット」で検索した人の結果に入ります。

## プロフィール画像（設定を忘れやすい箇所）

`tsukiyomi-profile-1080.png`（1080×1080・Designer作）を Threads のプロフィール画像に設定します。
Instagram 側のアイコンにも同じ画像を使ってください（同一ブランドとして認識させるため）。

- 表記は `五占術鑑定`。**AI表記なしで確定済み**（サイト・鑑定書・ココナラ出品文と統一）
- 円形トリミング前提の構図で、96px前後の表示でも「月＋ツキヨミ」が判読できるよう調整済み
- 表示名で検索語を拾い、アイコンはブランド認知に振る分担です。**アイコンに占術名を入れる必要はありません**（小さすぎて読めないため逆効果）

添付の画像ファイルはチャットで受け取ったものをそのままアップロードしてください（加工不要）。

## 作成日より効く問題: 過去の投稿履歴

**2025年10月に作って別用途で使っていた場合、過去投稿のジャンルが今と食い違うと、
おすすめに乗る相手がズレます。** Threads は過去の反応から「このアカウントは誰に見せるか」を
学習するので、無関係な投稿が残っていると占いに興味がある層に届きにくくなります。

対策は、占いと無関係な過去投稿を削除するか、**新規アカウントに切り替える**ことです。
アカウントの古さに価値がない以上、履歴が汚れているなら作り直した方が速いです。
判断材料として、過去投稿が10件未満なら削除、多いなら新規作成をおすすめします。

## 投稿側でやること（既に実装済みの範囲）

- 1日2〜3回（8/13/21時）。上限まで撃たない
- 同一文面を再投稿しない（重複回避は実装済み）
- 絵文字を置いてもらう型でコメント数を稼ぐ（コメントが表示回数に効いていた実測あり）
- 本文にURLを入れない
