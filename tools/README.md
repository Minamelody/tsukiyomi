# tools/

`pdfgen.py` はここに置く。Designer が管理する鑑定書PDFのHTML/CSS＋図版生成スクリプト。

`src/deliver-ui.js` は標準入力に以下のJSONを渡して `python3 tools/pdfgen.py --out <path>` を呼ぶ。

```json
{
  "display": "佐藤美咲",
  "plan": "bundle",
  "input": { "sei": "佐藤", "mei": "美咲", "birthday": "1995-07-15", "question": "..." },
  "readings": [
    { "type": "seimei", "name": "姓名判断", "summary": "...",
      "facts": { "五格": { "天格": 25, "...": 0 } },
      "sections": [ { "h": "見出し", "body": "本文" } ] }
  ]
}
```

`facts` は占術の計算確定値（五格の画数・命式の干支・引いたカード・ホロスコープ）。
図版はここから描く。`pdfgen.py` が無い場合、納品ツールはテキスト納品だけを返して落ちない。

---

## デザイン版（Designer）について

`pdfgen.py` は Designer 管理のデザイン版に差し替え済み。`figures.py` が同じ
ディレクトリに必要（無い場合は図版なしで生成を続ける）。JSONの契約は上のまま。

### レイアウトは種目数で自動切替

| plan | 構成 | ページ数 |
|---|---|---|
| 5種セット | 表紙 → 目次 → [扉 → 本文]×5 → 奥付 | 18 |
| 単品 | 表紙 → 本書について → 本文 → 奥付 | 5（全5種とも） |

単品は目次と扉を省き、代わりに「本書について」で**実際に計算している項目**を開示する。

### facts のどのキーを読んでいるか

図版は `facts` のキー名に依存する。**キー名を変えるときは事前連絡が必要**（値の追加は安全）。

| type | 読んでいるキー | 図版 |
|---|---|---|
| `seimei` | `姓名` / `画数.姓` / `画数.名` / `五格.{天格,人格,地格,外格,総格}` | 画数＋五格一覧 |
| `tarot` | `引いたカード[].{位置,カード,正逆}` | 引いた3枚（逆位置は反転） |
| `shichu` | `命式.{年柱,月柱,日柱,時柱}` / `日干` / `五行バランス` / `最も強い五行` / `欠けている五行` | 命式＋五行バランス |
| `astro` | `太陽星座` / `月星座` / `上昇宮` / `優勢エレメント` | ホロスコープ円 |
| `seiza` | （図版なし・扉の紋章のみ） | — |

`五格` は `"25画 吉（独特の才。個性で立つ）"` の形式を正規表現で分解している。
`日干` は `"丁（火・灯火）"`、星座系は `"蟹座（水・支配星月・…）"` の先頭語を取る。

**キー名が変わって図版が作れなくなった場合、stderr に警告を出して図版なしで続行する。**
黙って表が空になることはないので、`deliver-ui.js` 側で stderr を拾って画面に出すこと。

### デバッグ

```bash
# 生成したHTMLも書き出す
echo '<json>' | python3 tools/pdfgen.py --out /tmp/a.pdf --html /tmp/a.html
# 図版だけ単体で確認
python3 tools/figures.py --demo /tmp/figs
```
