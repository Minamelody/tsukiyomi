## 共通構造（5層）— これが「濃さ」の正体
1. **呼びかけ / 痛みの名指し** … 「早朝5時。もう起きている方」「支払いが多く通帳残高がカツカツなあなた」
   → 全員に向けず、特定の状況の人だけを名指しする。自分のことだと思った人だけが止まる。
2. **日付・時間の限定 + 暦の裏付け** … 「9/6は一粒万倍日×母倉日×天恩日」「5:00〜8:59だけ」「9月6日から9月7日」
   → 暦(選日)は検証可能な事実なので嘘にならず、権威と期限を同時に作れる。ツキヨミの強み(五占術)と噛み合う。
3. **絵文字1個のCTA** … 「🌊を置いてくださった方」「🗻を置けた人だけ」
   → 行動コストが極小。かつ返信数が伸びる=アルゴリズムが伸ばす。**本文にURLゼロ**（Threadsは本文URLでリーチが落ちる）。
4. **選別の言葉** … 「奇跡的に起きている方」「置けた人だけが」
   → 「受け取れる人だけ」の枠を作ると、入りたくなる。全員に配ると価値が消える。
5. **結果の約束（情景で書く）** … 「視えたまま正直に」「貧乏神が音をたてずにスッと消え去る」
   → 説明でなく情景。Bの「音をたてずにスッと」が効いている。形容詞より動作。

## 誘導を露骨にしない = 2段構え
本文では鑑定に触れない。絵文字を置いた人へ**返信で個別に**渡す。
- 1段目(投稿): 絵文字だけ求める。URL・価格・「無料鑑定はこちら」を一切書かない。
- 2段目(返信): 「視えたこと」を2〜3行その人向けに書き、最後に「もっと深く視るには生年月日が必要なので、こちらで出せます」程度で1回だけ触れる。
→ 投稿本文の変換率を捨てて、リーチと返信数を取る。動線はbioリンクが本線。

## 使ってはいけない表現（ツキヨミの場合）
- **「1000名以上を鑑定してきた私」型の実績値はNG** … ツキヨミは新規アカウントで実績ゼロ。数字を作ると嘘になり、後で必ず刺される。
  代替の権威付け: 「五占術（姓名判断・星座・タロット・四柱推命・西洋占星術）を重ねて視ます」= 手法の厚みで語る。これは事実。
- 断定的な効果保証（「必ず」「治る」「儲かる」）… 金銭・健康の断定は避ける。「貧乏神が消える」型は情景表現の範囲に留める。
- AI表記は入れない（2026-09-06にR社長がB案=全面非表示を選択済み）。

## カード生成連携（gen_cards.py・2026-09-06 受領 → 契約化）
- 配置: `design/cards/`（gen_cards.py + README + カード3種）。repo内の最終配置パスはEngineerのrepo作業で確定（候補: public/ か tools/）。
- 呼び出し: CLI=`python3 gen_cards.py -o <out> --spec '<json>'` / API=`from gen_cards import render; render(spec, out)`。t1/t2/t3 すべて同形。
- spec は v2 ジェネレータが投稿文面と同時に組み立てる（本文テンプレとカードは同一データから生成し、文の重複は禁止）。
- **エラー処理（必須・Designer指定）**: ValueError を捕捉 → その枠は投稿せずスキップ or specを作り直して再生成。崩れ画像は絶対に投稿しない。
- 長さ上限（gen_cards.py LIMITS テーブル・超えるとValueError）: t1=選日合計34字/選日名11字/date_label 20字/window 16字、t2=行22字×2〜3行、t3=行18〜20字×2〜3行。
- 依存: gen_brand.py（ブランド描画プリミティブ）を同梱必須（探索5候補パス・無ければ探索パス表示して停止）。絵文字フォント欠如時は絵文字のみ省略して続行。私のsandboxはPillow+絵文字フォントあり・gen_brand.pyは未受領（実描画確認は配置パス確定後にDesignerが実施）。
- 運用約束（コードで縛れない3点・ランナー側も遵守）: 選日は実在のみ / 実績数値なし / 時限カードは当日限り破棄・失敗枠の翌日流用禁止。

## T1の出し分け（rarity.plan 実装・2026-09-06確定・senjitsu v1.1）
- **T1（選日主題）は `rarity.plan(date).use_T1=True` の日のみ**（2026年実測79日/365日=22%）。
- 単独ラベル（天恩日のみ59日・母倉日のみ42日、連続9日ブロックも存在）はT2/T3に流す。3種重なりは年5日（5/5・7/7・9/6・11/4・12/1）しかないため、単独と同じ熱量で語らない。
- 時間窓は `senjitsu.peak_window(date)['label']`（その日の十二支の時辰）を spec.window に入れる。日ごとに変わるため使い回しなし。例: 2026-09-06（癸未）= 未の刻 13:00〜14:59。
- **参考投稿の「5:00〜8:59」は卯の日限定（例: 2026-05-05）なので流用禁止**（暦の裏付けのない窓を作らない）。
