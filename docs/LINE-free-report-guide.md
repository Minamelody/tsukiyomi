# LINE無料鑑定ツール 操作手順（R社長用）

無料鑑定ツールには2つの使い方があります。おすすめは **A. Safariで開くHTML版** です（iPhone・パソコンどちらでも、タップだけで使えます）。必要に応じて B. コマンド版（Node.js）も使えます。どちらも**完全オフライン・個人情報は外に出ません**。

## A. HTML版の開き方（Safari対応・推奨）

ファイル名は `line-fortune.html`（1ファイル完結）。この1つのファイルだけで動きます。

### 開き方

- **Mac の Safari**: ファイルを**ダブルクリック**すれば Safari で開きます。うまく開かないときは、Finder でファイルを右クリック →「このアプリケーションで開く」→ Safari を選んでください。
- **iPhone の Safari**: ファイルを **「ファイル」アプリ**に保存（AirDrop やメール添付から保存）→ 保存した `line-fortune.html` をタップすれば Safari で開きます。

ネット接続・サーバー・APIキー・Node.js のインストールは一切不要です。

### 使い方（3ステップ）

1. **姓**（任意）と**名**（任意）を入力（名字だけでも、両方でもOK。空欄でも動きます）。
2. **生年月日**を入力（必須）して**「鑑定する」**を押す。
3. 鑑定文（500〜800字・5種）が表示されるので、**「結果をコピー（LINEへ）」**を押し、**LINEの相手に貼り付けて送信**するだけです。

名前を入れなかった場合は、姓名判断の欄が自動で「お名前を教えていただければ…」に変わります。

## B. コマンド版（Node.js・パソコン用）

パソコンでコマンドを打つ使い方です。サーバーやWeb・APIキーは不要で、完全にオフラインです。

### 事前準備（初回のみ）

1. パソコンに **Node.js（バージョン18以上）** が入っていること。
   - 確認: ターミナル（Windows=コマンドプロンプト／Mac=ターミナル）で `node -v` を実行 → 数字が表示されればOK。
   - 入っていなければ https://nodejs.org から「LTS」をインストール。
2. ツール一式（このフォルダ一式）をパソコンの任意の場所に置く。

### 使い方（3ステップ）

#### ① 起動
ターミナルでツールのフォルダへ移動し、次を実行します。

```
cd （ツールを置いたフォルダのパス）
node src/line-fortune.js --sei 佐藤 --mei 美咲 --birthday 1995-07-15
```

- `--sei` … 姓
- `--mei` … 名
- `--birthday` … 生年月日（**西暦-月-日** 形式。例: 1995-07-15）

#### ② 入力
上の例の「佐藤」「美咲」「1995-07-15」の部分を、お客さまの情報に書き換えて実行します。
名前がわからない場合は `--sei` と `--mei` を外してください（姓名判断の欄が自動で「お名前を教えていただければ…」に変わります）。

#### ③ 結果をコピーしてLINEへ
実行すると鑑定文（500〜800字・5種）が表示されます。それを**全文コピーして、LINEの相手に貼り付ける**だけです。

## 入力例（3つ）

1. `node src/line-fortune.js --sei 佐藤 --mei 美咲 --birthday 1995-07-15`
2. `node src/line-fortune.js --sei 山田 --mei 花子 --birthday 1990-03-25`
3. `node src/line-fortune.js --birthday 1988-12-01`  ← 名前なし

## 補足

- 鑑定文は**その場で決まり、同じ人なら毎回同じ文面**です（決定論・占いの信用を保つため）。HTML版とコマンド版は**同じロジック・同じ辞書**なので、どちらで出しても同じ文言になります。
- ネット接続不要・個人情報は端末内で完結し、外部に送信されません。
